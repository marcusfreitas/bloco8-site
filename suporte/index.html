Suporte

Dúvidas, problemas ou sugestões sobre o Flow8? Fale com a gente.

E-mail: contato@bloco8.com

Para ajudar a entender o problema, conte o modelo do aparelho, a versão do sistema e a versão do app (em Configurações → Sobre).

Seus dados

O Flow8 não tem conta: os treinos ficam só no seu aparelho. Para levar seus dados para outro aparelho, use Configurações → Backup e restauração. Para planilhas ou relatório em PDF, use Configurações → Exportar dados. Para apagar tudo, use Configurações → Apagar todos os dados locais.
